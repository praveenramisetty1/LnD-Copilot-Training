### Main Endpoint

### Technology Stack

| Layer | POC (Implemented) | Production Target |
|-------|-------------------|-------------------|
| API Framework | Python FastAPI + Uvicorn | Same |
| Auth | API Key + brute-force lockout (10 failures → 5min lock) | JWT + OAuth 2.0 |
| Rate Limiting | In-memory Token Bucket (ADR-002) | Redis INCR + TTL |
| NFR Parser | Custom Python module | Same |
| Model Selector | Weighted scoring: Cost 40% / Latency 30% / Accuracy 30% | Same |
| Failover Engine | 4-level + Circuit Breaker (ADR-009) | Same |
| Semantic Cache | Pure-Python cosine similarity, threshold 0.75 (ADR-003) | Qdrant L2 + Redis L1 + Ada-002 embeddings |
| Analytics Store | `data/analytics.json` (ADR-010) | TimescaleDB hypertable |
| LLM Providers | Simulated — OpenAI, Anthropic, Google (ADR-004) | Real provider APIs |
| Frontend UI | Not built (Future Scope) | React 18+ |
| NLU Interface | Not built (Future Scope, ADR-007) | NLU → SQL engine |

### Component Flow

```
Client Request
    │
    ▼
[FastAPI Gateway]
    ├── Auth Middleware       (API Key validation, brute-force lockout)
    ├── Rate Limit Middleware (In-memory Token Bucket by tier)
    └── NFR Parser           (X-NFR-Latency / X-NFR-Cost / X-NFR-Accuracy)
         │
         ▼
    [Router / Orchestrator]
         │
         ├──► [Semantic Cache]     ──► HIT  → return cached response
         │     (cosine ≥ 0.75)         MISS → continue
         │
         ├──► [Model Selector]     ──► Weighted scoring (Cost 40%, Latency 30%, Accuracy 30%)
         │
         ├──► [Provider Registry]  ──► Model catalog + failover chains
         │
         ├──► [Failover Engine]    ──► L1: Same model / different provider
         │     + Circuit Breaker       L2: Same model / different region
         │                             L3: Different model / same family
         │                             L4: Different model / different family
         │                             CB: 5 failures → 60s OPEN → 3 probes → CLOSED
         │
         └──► [Analytics Collector] ── data/analytics.json
```
